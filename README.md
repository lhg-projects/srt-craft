# SRT 字幕校正 · SRT Craft

> **一句话**：SRT 字幕 + 你的原始文稿 → 校正版 SRT。时间轴一个毫秒都不动，只改文本——专为「AI 口播视频的剪映字幕纠错」打造。
>
> **本地启动**：`python app.py` → http://127.0.0.1:8765

（lhg-skills 出品）给剪映/口播视频创作者的字幕纠错工具：语音识别的字幕总有同音错字（力勤/利勤、镍钴/孽股），人工逐条改很痛苦。把**你写的原稿**贴进来，工具用拼音对齐算法自动找出并修正错字，产出修正版 SRT 直接导入剪映——**全程不碰剪映草稿文件，无覆盖风险**。

## 为什么是 SRT 而不是改草稿

改剪映草稿要和它的内部缓存（识别文本/逐字时间轴/关键词高亮）搏斗，剪映编辑器还随时可能用内存快照覆盖你的修改——实测会「显示成功但画面不变」。SRT 是剪映自己的导入格式：**文本→字幕→导入字幕**，导入后由剪映全权管理，零风险。

## 三种校正模式

| 模式 | 依赖 | 能修 | 速度 |
|---|---|---|---|
| 📢 拼音对齐（默认） | 无，纯本地 | 同音错字（力勤↔利勤）、标点、数字读法 | 秒级 |
| 🔧 重建模式 | 无，纯本地 | 多字/漏字、读音不同的错字；以原稿为准按时间轴重新分配 | 秒级 |
| 🤖 AI 校正 | 需配置 OpenAI 兼容服务 | 语义级改写、乱序、代词指代 | 1-4 分钟 |

建议流程：先跑拼音对齐看报告 → 有残留再勾 AI 校正。

**有原稿 / 无原稿的判定逻辑**（工具自动处理，也适用于你自己判断）：

- **有口播稿**：有对齐参照系，拼音对齐成立 → 默认本地秒级校正，AI 可选（对付改写过的段落）
- **无口播稿**（录视频时脱稿）：没有参照系，拼音对齐不成立 → **必须走 AI**，工具会自动勾选并锁定 AI 模式（前端锁定 + 服务端强制，防绕过），切换到「AI 校对」专用提示词——只修上下文可判断的同音错字/重复字/专名错写，口误和口语表达保持原样，宁少改不误改
- 无原稿 + AI 未配置：提交时明确报错并引导到「⚙️ AI 设置」

## 安装

**Windows**：双击 `start_windows.bat`（自动创建虚拟环境并安装依赖），浏览器开 <http://127.0.0.1:8765>

**macOS**：

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

依赖：Python 3.10+；可选 ffmpeg/ffprobe 在 PATH（仅「从剪映草稿生成 SRT」的高级功能需要）。

## 使用

1. **获取 SRT**：剪映里 文本 → 字幕 → 导出字幕（`.srt`），或在工具里选草稿一键生成（需本机装有剪映）
2. **贴入原稿**：把你写的口播文稿粘进「② 原始文稿」
3. **开始校正**：报告逐条列出原句与新句，供你核对
4. **下载修正版 .srt** → 剪映里导入字幕，删除旧字幕轨，完成

## AI 校正（可选）

默认三选二（拼音/重建）完全本地、零配置。AI 校正需在页面右上「⚙️ AI 设置」填入任意 OpenAI 兼容服务（地址/模型/密钥），密钥只保存在本机 `config.json`（已在 .gitignore），不上传到任何地方。

## 从剪映草稿直接生成 SRT（可选增强）

本机装有剪映专业版时，页面可一键把草稿字幕转成 SRT（自动探测草稿目录：macOS `~/Movies/JianyingPro/...`、Windows `%LOCALAPPDATA%\JianyingPro\...`；支持剪映 6+ 加密草稿本地解密，解密不联网）。

## 什么时候用 / 什么时候不用

**用它，当你**：用剪映做口播/解说视频，语音识别字幕错字多，手上有逐字稿。

**别用它，当你**：字幕需要翻译（这是纠错不是翻译）；没有原稿只有录音（可先用剪映识别字幕再校正）。
